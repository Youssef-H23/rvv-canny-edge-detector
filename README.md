# Canny Edge Detection on RISC-V (RVV)

This repository contains the implementation of a Canny Edge Detection pipeline optimized for the RISC-V architecture, specifically leveraging the RISC-V Vector Extension (RVV 1.0). 

The project follows a "Host-Driven Development" workflow: the scalar baseline and unit tests are developed and verified natively on the host machine before being cross-compiled and tested on a RISC-V emulator (QEMU).

## 📂 Project Structure

```text
canny-rv-project/
├── Makefile               # Dual-target build system (Host & RISC-V)
├── src/                   # C++ source files (Pipeline logic)
│   ├── main.cpp           # Main pipeline execution entry point
├── tests/                 # C++ unit tests
│   └── host_tests.cpp     # GoogleTest suite for host-side verification
└── build/                 # Auto-generated directory for compiled binaries
    ├── host/              # Native executables (generated by `make test`)
    └── rv/                # Cross-compiled executables (generated by `make canny_rv`)
```

## 🛠️ Prerequisites & Environment

Before building, ensure your environment (e.g., WSL2 / Ubuntu 24.04) has the following dependencies installed:

1. **Host Compiler:** Standard `g++` (for native testing and verification).
2. **RISC-V Toolchain:** `riscv64-unknown-elf-g++` built from source with Vector extension support (`--with-arch=rv64gcv`).
3. **QEMU Emulator:** `qemu-riscv64` for executing RISC-V binaries on the host machine.
4. **GoogleTest:** Installed locally in your user directory (`~/.local/include` and `~/.local/lib`).

## 🚀 Build and Execution Guide

This project utilizes a dual-target `Makefile` to seamlessly switch between host-side debugging and RISC-V emulation. Run all commands from the root directory.

### 1. Host-Side Testing (Algorithm Verification)
To compile and run the GoogleTest suite natively on your machine:
```bash
make test
```
*Use this target constantly during development to verify that your C++ logic works perfectly before attempting cross-compilation.*

### 2. Cross-Compiling for RISC-V
To cross-compile the main application for the RISC-V architecture using the Vector Extension:
```bash
make canny_rv
```
*This uses your RISC-V toolchain to generate the `canny_pipeline.elf` binary inside the `build/rv/` directory.

### 3. Running on QEMU Emulator
To execute the cross-compiled RISC-V binary via QEMU:
```bash
make run
```
*Note: The Makefile passes the `VLEN=128` parameter to QEMU by default, simulating a 128-bit vector register length. Do not hardcode this value in your C++ code!*

### 4. Sweeping Vector Lengths (VLEN)
To prove the implementation is Vector Length Agnostic (VLA), you can run the executable across multiple hardware configurations automatically:
```bash
make sweep
```
*This executes the RISC-V binary on QEMU with VLEN set to 128, 256 and 512 bits consecutively.*

### 5. Cleaning the Workspace
To remove all generated build artifacts, object files, and binaries:
```bash
make clean
```
